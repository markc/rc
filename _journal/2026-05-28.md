# 2026-05-28 — CLAUDE.md scaffold + sshm `next`→`end` fixup

## Changes

- **sshm**: replaced six stray `next` block-terminators with `end` across
  `ssh_init`, `host_list`, `host_test`, `key_list`, and `do_perms`. These were
  leftover from an earlier Mix syntax (or a partial bash port) — current Mix
  uses `end` for both `for each` and `if` blocks, so the file was failing to
  parse cleanly in places that relied on those functions.
- **CLAUDE.md**: added a project guide for future Claude sessions. Covers the
  load chain (`~/.mixrc` → `_mixrc` → glob `_lib/*.mix`), the
  `_lib`/`_bin`/`_etc` taxonomy and which is auto-sourced, the NN- load-order
  contract, and the Mix-language gotchas already encountered here (sigil
  pre-assignment requirement, leading-`~` escape). Includes the realistic
  verification loops since there's no test suite.

## Notes

- The `next` keyword does not exist in current Mix — anywhere it appears in
  ported scripts it should become `end`. Worth keeping an eye out in the rest
  of the bash-to-Mix port work in `~/.cosmix/`.
- CLAUDE.md deliberately points future sessions at fixing root causes in
  `cosmix-lib-mix` rather than accumulating workarounds in this scaffold, per
  the universal Mix-first policy.

## sshm sync rewrite

- Original `do_sync` rsync'd the entire `~/.cosmix/` dev tree (~18 MB
  source, `_doc/`, `_journal/`, `_state/`, `src/test/`, `.claude/`, …) to
  the remote, excluding only `.git` and `target/`. That violates the
  dev-box-vs-artifact boundary — remotes get artifacts, not source. Caught
  the first time `sshm sync obsv` was run from a fresh session.
- Rewrote `do_sync` at `_bin/sshm:364` to push only `~/.rc/`, excluding
  `.git`, `_journal`, `_doc`. Added a second phase that probes the remote
  for `/opt/cosmix/bin/mix` and scp's the local binary if missing (interim
  bootstrap until mix has its own repo + release artifacts). Updated the
  help text accordingly.
- Cleaned `~/.cosmix/`, `~/.rc/.git`, `~/.rc/_journal`, `~/.rc/_doc` off
  `obsv`. Re-synced to confirm: 4.3 KB pushed instead of 4.6 MB, dev dirs
  excluded.
